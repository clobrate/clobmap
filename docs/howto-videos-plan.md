# How-to videos plan

A concrete plan to ship a first batch of clobmap how-to videos, tuned
to a solo workflow.

## 1. Pick the videos (one afternoon)

Short list ordered by what gets users to "aha" fastest. Suggested
first batch:

1. **60-sec hero demo** — opens app, types YAML, mind-map appears,
   drags a node. Goes on the clobmap.com landing page.
2. **"Your first mind map" (2 min)** — create a file, add nodes, edit
   names, save. The onboarding video.
3. **YAML ↔ mind-map duality (90 sec)** — the differentiator. Toggle
   views, edit either side, show they stay in sync.
4. **Tags & filter view (2 min)** — the 1.2.0 headline feature. Add
   tags, open the tag tree, hierarchy filter.
5. **Power-user shortcuts (90 sec)** — keyboard nav, tabs, notes
   popup.

Five videos, ~8 minutes total. Resist doing more on the first pass.

## 2. Script each one (30 min per video)

Three-beat structure:

- **Hook (5 sec):** "Mind-maps you can edit as YAML." Show the result
  up front.
- **Demo (60–90 sec):** one task, one outcome. No tangents.
- **CTA (5 sec):** "clobmap.com — free, open source."

Write the script as bullet points of *what you'll click*, not a
word-for-word narration. Improvise the voiceover from those bullets —
sounds more natural and is faster to re-record.

## 3. Prep the app (15 min)

- Make a clean demo YAML file with realistic-looking content (not
  `foo/bar`). E.g. a product roadmap, a book outline, a trip plan.
- Set the theme you want on camera (dark looks more produced on
  landing pages, light reads better for screenshots).
- Bump font size to ~16–18px in settings so text is legible at
  YouTube-compressed bitrate.
- Quit other apps; silence notifications (Do Not Disturb).

## 4. Record (1–2 hours for the batch)

In Tella:

- Record screen + webcam in one session, all five videos back-to-back.
  Cheaper context-switch than spreading across days.
- Re-record any clip that flubs — don't try to do whole videos in one
  take.
- Talk slightly slower than feels natural; viewers won't notice, but
  mumbled words sound amateur.

## 5. Edit + export (1 hour)

- Trim dead air at the start/end.
- Let Tella's auto-zoom do its thing; manually zoom on small UI bits
  (the status bar autosave message would be a good one).
- Add captions — Tella generates them; spend 5 min cleaning typos.
  Captions roughly double watch time.
- Export 1080p MP4.

## 6. Publish

- **Landing page:** embed the 60-sec hero. Auto-play, muted, looped.
- **YouTube:** one channel, all five videos. Link from README.md and
  the in-app About dialog.
- **README.md:** GIF of the hero demo at the top + YouTube link. GIFs
  autoplay in GitHub, video previews don't.

## 7. Iterate

Ship the batch, watch the YouTube retention graphs after a week,
re-record whichever has the worst drop-off. Don't try to make any
single video perfect on the first cut.

## Time budget

~6 hours from blank slate to five videos live.
